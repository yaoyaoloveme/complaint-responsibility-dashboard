# 值班店长客诉责任分析看板

公开网址：https://yaoyaoloveme.github.io/complaint-responsibility-dashboard/

当前数据期间：2026-11-02 至 2026-11-08，共 3,247 条责任记录。

支持商家 APP / 天润工单区分、一线二线统计、成立率、问题分布、人员字段、明细下钻和筛选后 CSV 导出。

每条原始责任记录分别统计，不按工单号或稽查单号去重。成立与不成立均按已确认的 B/C 分类口径归类。K 列为被投诉客服/值班店长，T 列为判责归因客服/完成处理人。

这是当前批次的静态快照。更新 `index.html` 并推送到 `main` 分支后，GitHub Actions 会自动重新发布。

网站无需登录；已发布的看板及内嵌明细均公开可见。
